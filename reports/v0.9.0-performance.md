# v0.9.0 local performance measurements

Host: macOS Darwin 25.4.0, arm64, Mac16,5, Apple M4 Max, 128 GiB RAM. Shell benchmark Node v26.7.0; real integration host VS Code 1.110.0. These are measurements on one machine, not a cross-platform guarantee.

Method: `node --expose-gc scripts/benchmark-bundle.cjs` in fresh processes. The script imports the built production bundle with a VS Code API stand-in, performs GC, records import time and memory deltas, then creates representative lazy-operation factories. It measures import/factory loading, not full extension activation. The real host integration separately times activation, panel creation, the first Base64 transform and 20 repeated transforms. Real UI tests cover search, keyboard execution, 10 host open/close cycles and small windows; no fabricated timings are assigned to those qualitative checks.

Baseline source: commit 540e2c2. One baseline import sample: 18.2 ms, +17.4 MiB RSS, +1.4 MiB heap. Five updated import samples: 19.8, 19.8, 18.1, 18.6, 18.9 ms (median 18.9 ms); RSS +17.4–17.6 MiB, heap +1.4 MiB. Median change from the single baseline sample: +0.7 ms (+3.8%). Zero operation chunks are eagerly loaded in every sample. Raw results are in `v0.9.0-logs/benchmark-baseline.json` and `benchmark-final-1.json` through `benchmark-final-5.json`.

The baseline real-host sample measured activation 25.44 ms, panel construction 0.94 ms, first Base64 1.39 ms and repeated mean 0.092 ms. The later 20-check sample measured 28.15 ms, 0.95 ms, 1.42 ms and 0.087 ms respectively. Integration reports include the final heap after more operation families have loaded; that value is not directly comparable to the baseline heap with fewer tests/chunks.

These samples do not reveal a large startup regression. A single baseline and changing operation workloads cannot establish statistical absence of all regressions. No sustained memory-leak profile, general expensive-operation throughput claim or Linux/macOS x64 performance conclusion is made. The final installed-host measurements are retained in the release readiness evidence.
